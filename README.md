# 🛡️ Scam Shield for Elders

An AI-powered scam detection application designed to help elderly people identify fraudulent SMS and WhatsApp messages.

## Project Overview

Scam Shield analyses suspicious messages and classifies them into three categories:

- SCAM
- SUSPICIOUS
- SAFE

It provides simple explanations and safety recommendations in English, Hindi and Kannada.

## Technology Stack

- Python
- FastAPI
- React
- Vite
- Tailwind CSS
- Google Gemini AI

## Project Structure

- `backend/` – Python backend and scam detection engine.
- `frontend/` – React user interface.
- `tests/` – Automated testing.
- `docs/` – Project documentation and screenshots.
